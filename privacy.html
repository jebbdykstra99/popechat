2. Information we collect

  • Account data when you register: email address, password (stored by our auth provider as hashes), display name / handle, and a site identifier (siteId).
  • Sign-in providers: if Google (or another provider) is enabled, we receive identifiers and profile fields the provider shares with us when you authorize sign-in.
  • Content you submit: posts, replies, images, polls, direct messages (where enabled), reports, and similar UGC.
  • Usage / device data: approximate logs such as IP address, browser type, referring URL, timestamps, and App Check / abuse-prevention signals needed to secure Firebase Auth, Firestore, and Storage.
  • Automated-traffic signals: SubX, LLC's visit records do not store your browser's user agent, brand headers, language settings, or automation (headless or webdriver) flags. Google Cloud's standard request logs for the visit beacon record the IP address, browser user agent and referring page along with the visitor ID, and are kept for about 30 days. They may be reviewed to detect abuse or automated traffic.
  • Unique-visitor ID: to count unique visitors, SubX, LLC has each browser create a random, anonymous visitor ID, kept in the browser's local storage as subx.vid, and sends it with the visit beacon. SubX, LLC's visit records do not include a name, email address, account ID, or IP address. Google Cloud's standard request logs for the visit beacon record the IP address, browser user agent and referring page along with the visitor ID, and are kept for about 30 days. Individual visit records are deleted after about 90 days, but SubX, LLC keeps a record of each visitor ID seen on popechat and the dates it was first and last seen for up to 25 months after it was last seen, so long-term unique-visitor counts stay accurate. Clearing the browser's site data creates a new ID. To ask SubX, LLC to delete a visitor ID, email takedown@subx.it with the subject “Delete my visitor ID: popechat” and, if you can, the subx.vid value from your browser. SubX, LLC does not use the visitor ID for advertising or cross-site tracking, does not combine it with other data to identify you, and does not sell or share it. If you are in the EU, UK, or Switzerland, SubX, LLC keeps this record on the basis of its legitimate interest in accurate audience counts, and you may object or request deletion at the address above.
  • Cookies / local storage: session and preference data required to keep you signed in and remember UI settings. We do not currently run third-party advertising pixels on the Service; if that changes, we will update this Policy.

Backend services for the Service currently include Google Firebase on project subx-skins (Authentication, Cloud Firestore, Cloud Storage, App Check). Google’s processing is described in Google’s cloud / Firebase terms and privacy documentation.
